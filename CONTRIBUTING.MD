## How to contribute
Because of the nature of this project, and the restricted hardware it has to run on, the contributions needs to follow strict conventions, so we do not accept any outside contributions. If you are interested in contributing to the project:
- [Go to our Discord](https://discord.com/channels/1498850477545357482/1499247606230941786)
- Get the applicant role
- You will be pinged in a new private thread by Elizabeth bot
- Fill out the form, which is linked in that thread

**PRs from non-team members will not be merged.**
